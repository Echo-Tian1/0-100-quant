## ML量化的核心公式

$$R_{t+1} = f(X_t) + \varepsilon_t$$

$X_t$ 是 t 时刻已知的因子特征，$f$ 是 ML 模型。

**Garbage In, Garbage Out** — 特征工程决定模型效果的上限。

---

## 特征工程四步流水线

```
原始数据 → 缺失值处理 → 去极值 → 标准化 → 特征构造 → 建模就绪
```

---

## 1. 缺失值处理

### 金融数据缺失的来源

| 原因 | 说明 |
|------|------|
| 停牌 | 重大资产重组等期间无交易 |
| 上市时间不同 | 新股历史数据短 |
| API 遗漏 | 数据源返回不完整 |
| 涨跌停 | 极端行情无成交 |

### 五种策略对比

| 策略 | 原理 | 优点 | 缺点 |
|------|------|------|------|
| **直接删除** | `dropna()` | 最简单 | 丢失信息，时序断裂 |
| **均值填充** | `fillna(mean)` | 简单 | ⚠️ 低估波动率 |
| **中位数填充** | `fillna(median)` | 对极值鲁棒 | 同样低估波动 |
| **前向填充** | `ffill()` | 保持时序连续性 | 连续缺失值会重复 |
| **前向+后向组合** | `ffill().bfill()` | ✅ 金融默认选择 | 大量连续缺失仍需注意 |

### 实战推荐

```python
# 金融时序缺失值处理的默认做法
df = df.ffill().bfill()
```

**为什么不用均值填充？** 均值填充会严重低估波动率——而波动率是金融数据最核心的信息。

### 策略选择指南

| 场景 | 推荐策略 |
|------|---------|
| 日线停牌数据 | 前向填充 (ffill) |
| 月度宏观指标 | 线性插值 |
| 横截面因子 | 中位数填充 |
| 大量连续缺失 (>30天) | 考虑剔除该股票 |
| 缺失率 > 50% | 直接剔除该股票 |

## 2. 去极值

### 三种方法

| 方法 | 原理 | 公式 | 推荐场景 |
|------|------|------|---------|
| **Winsorize** | 百分位数截尾 | `clip(Q1%, Q99%)` | ✅ 默认选择 |
| **Z-score** | 正态假设截尾 | `clip(μ±3σ)` | 正态性好的因子 |
| **MAD** | 中位数绝对偏差 | `clip(med±3×MAD)` | 偏态严重的数据 |

### Winsorize 实战

```python
def winsorize_series(s, lower=0.01, upper=0.99):
    lo, hi = s.quantile(lower), s.quantile(upper)
    return s.clip(lo, hi)
```

### 方法对比

| | Winsorize | Z-score | MAD |
|------|-----------|---------|-----|
| 对异常值的鲁棒性 | ✅ 好 | ❌ 受极值影响 | ✅ 很好 |
| 对分布假设 | 无 | 正态分布 | 无 |
| 参数选择 | 分位数 (1%/99%) | σ 倍数 (3) | MAD 倍数 (3) |

## 3. 标准化

### 三种 Scaler

| Scaler | 公式 | 输出范围 | 适用场景 |
|--------|------|---------|---------|
| **StandardScaler** | $(X-\mu)/\sigma$ | 均值0，标准差1 | 正态数据、PCA、线性模型 |
| **MinMaxScaler** | $(X-X_{min})/(X_{max}-X_{min})$ | [0, 1] | 神经网络 |
| **RobustScaler** | $(X-Q_{50})/(Q_{75}-Q_{25})$ | 中位数中心化 | ✅ 金融数据（含异常值） |

### 量化因子的默认选择

```python
from sklearn.preprocessing import RobustScaler
scaler = RobustScaler()
X_scaled = scaler.fit_transform(X)
```

> 为什么用 RobustScaler？金融数据常有肥尾，中位数和 IQR 比均值和标准差更鲁棒。

## 4. 特征构造：50+ 因子

### 因子分类体系

| 类别 | 数量 | 示例因子 |
|------|------|---------|
| **动量因子** | ~12 | `mom_20d`, `mom_60d`, `sharpe_60d` |
| **波动率因子** | ~8 | `vol_20d`, `upvol_20d`, `downvol_20d` |
| **成交量因子** | ~8 | `vol_ratio_5d`, `vol_price_corr_20d` |
| **技术指标** | ~12 | `rsi_14d`, `macd`, `bb_position_20d` |
| **价格形态** | ~6 | `ma_dev_20d`, `high_proximity_60d` |
| **高阶矩** | ~4 | `skew_20d`, `kurt_20d` |
| **路径因子** | ~4 | `maxdd_60d`, `ret_vol_ratio_20d` |
| **横截面排名** | ~2 | `mom_20d_rank` |

### 动量因子的经典设定

```python
# Jegadeesh-Titman 风格：过去12个月累计收益（跳过最近1个月）
momentum = price.pct_change(252)  # 等权重
# 或
momentum = (price / price.shift(252)) - 1

# 跳过最近1个月（短期反转效应修正）
momentum_skip1 = price.shift(21).pct_change(252)
```

## 5. 时间序列数据划分 —— 最重要的一个环节

### 为什么不能随机划分？

| 问题 | 说明 |
|------|------|
| **前视偏差** | 用未来数据预测过去 — 模型作弊 |
| **时序自相关** | t 和 t+1 的特征高度相关，随机划分导致"泄露" |
| **市场状态变化** | 混合不同市场状态无法评估泛化能力 |

### 正确 vs 错误

```python
# ❌ 错误：随机划分（信息泄露）
from sklearn.model_selection import train_test_split
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3)

# ✅ 正确：时间顺序划分
split = int(len(X) * 0.7)
X_train, X_test = X[:split], X[split:]  # 时间在前的是训练，在后的是测试
```

### 三层验证体系

| 层次 | 方法 | 用途 |
|------|------|------|
| 开发阶段 | 简单时间切分 | 快速迭代 |
| 调参阶段 | TimeSeriesSplit | 稳健调参 |
| 最终验证 | 样本外数据 | **只用一次** |

### TimeSeriesSplit

```python
from sklearn.model_selection import TimeSeriesSplit
tscv = TimeSeriesSplit(n_splits=4)
for train_idx, test_idx in tscv.split(X):
    # train_idx 总是在 test_idx 之前
    ...
```

每次 fold 的训练集越来越大，测试集紧跟其后——模拟了"随时间推移不断积累数据"的实盘场景。

## 7. 因子 IC 检验

### IC (Information Coefficient)

$$IC = \text{rank\_corr}(因子_t, 收益_{t+1})$$

| 指标 | 含义 | 优秀标准 |
|------|------|---------|
| IC 均值 | 预测方向准确性 | > 0.03 |
| IC 标准差 | 预测稳定性 | < 0.15 |
| IR (IC/σ) | 信息比率 | > 0.3 |
| IC > 0 比例 | 正确率 | > 55% |

## 踩坑记录

### 🕳️ 坑1：随机划分时序数据
**后果**：回测年化 50%，实盘年化 -20%。

### 🕳️ 坑2：先标准化再划分
**后果**：测试集的均值和标准差"泄漏"到训练过程中——前视偏差的隐蔽形式。

```python
# ❌ 错误
scaler.fit(all_data)  # 用了测试集信息
# ✅ 正确
scaler.fit(train_data)  # 只用训练集
test_data = scaler.transform(test_data)  # 测试集只用 transform
```

### 🕳️ 坑3：均值填充时序数据
**后果**：波动率被低估 30-50%，模型学到的是"假平稳"信号。

### 🕳️ 坑4：忽略因子间多重共线性
动量20D 和动量60D 的相关系数往往 > 0.7。直接全扔进模型导致过拟合。解决：相关性 > 0.8 的因子做筛选，或用 PCA 降维。
