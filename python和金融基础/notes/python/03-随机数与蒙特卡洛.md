## 随机数生成（新版 API）

```python
rng = np.random.default_rng(42)  # 推荐，可复现

# 连续分布
rng.uniform(0, 1, size=1000)     # 均匀分布 [0, 1)
rng.normal(0, 1, size=1000)      # 正态分布 N(0,1)
rng.standard_t(df=5, size=1000)  # t 分布（厚尾，量化常用）

# 离散分布
rng.integers(1, 7, size=1000)    # 整数 [1, 6]（骰子）
rng.choice([0, 1], size=1000)    # 二选一

# 排列
rng.permutation(10)              # 随机排列 0-9
rng.choice(100, size=10, replace=False)  # 无重复抽样
```

> ⚠️ 一定用 `default_rng()` 而非旧版 `np.random.rand()`，线程安全且可复现

## 种子（Seed）的作用

```python
rng1 = np.random.default_rng(42)
rng2 = np.random.default_rng(42)
print(rng1.normal() == rng2.normal())  # True，每次运行结果相同

rng3 = np.random.default_rng()  # 不指定种子 → 每次不同
```

种子 = 可复现性 = 实验可验证 = 论文可复现

## 蒙特卡洛估算 π

```python
n = 1_000_000
x = rng.uniform(-1, 1, n)
y = rng.uniform(-1, 1, n)
inside = (x**2 + y**2) <= 1
pi_estimate = inside.mean() * 4  # ≈ 3.14159
```

**原理**：单位正方形内随机撒点，落在单位圆内的比例 = π/4

## 蒙特卡洛模拟股票价格

```python
S0 = 100       # 初始价格
mu = 0.0005    # 日均收益
sigma = 0.015  # 日波动率
T = 252        # 交易日数
n_sims = 10000 # 模拟次数

# GBM（几何布朗运动）
Z = rng.standard_normal((T, n_sims))
S = S0 * np.exp(np.cumsum((mu - 0.5*sigma**2) + sigma*Z, axis=0))

# 最终价格分布
final_prices = S[-1]
print(f"期望价格: {final_prices.mean():.2f}")
print(f"5%分位: {np.percentile(final_prices, 5):.2f}")  # VaR
print(f"95%分位: {np.percentile(final_prices, 95):.2f}")
```

## Bootstrap 重抽样

```python
# 用历史数据估计统计量的不确定性
returns = np.array([...])  # 历史日收益率

n_bootstrap = 10000
boot_means = []
for _ in range(n_bootstrap):
    sample = rng.choice(returns, size=len(returns), replace=True)
    boot_means.append(sample.mean())

# 均值的 95% 置信区间
ci_lower = np.percentile(boot_means, 2.5)
ci_upper = np.percentile(boot_means, 97.5)
print(f"均值 95% CI: [{ci_lower:.6f}, {ci_upper:.6f}]")
```

## 收益率分布模拟

```python
# 正态 vs t 分布（厚尾）
n = 10000
normal_returns = rng.normal(0, 0.015, n)
t_returns = rng.standard_t(df=5, size=n) * 0.015 / np.sqrt(5/(5-2))

# t 分布产生更多极端值
print(f"正态 |r|>3σ: {(abs(normal_returns) > 0.045).mean():.4f}")
print(f"t分布 |r|>3σ: {(abs(t_returns) > 0.045).mean():.4f}")
```

## 常见分布速查

| 分布 | 函数 | 用途 |
|------|------|------|
| 均匀 | `uniform(a, b)` | 等概率随机 |
| 正态 | `normal(mu, sigma)` | 收益率建模（基准） |
| t 分布 | `standard_t(df)` | 厚尾收益率（更现实） |
| 对数正态 | `lognormal(mu, sigma)` | 价格模拟（保证正值） |
| 泊松 | `poisson(lam)` | 事件计数（订单到达） |
| 二项 | `binomial(n, p)` | 胜率模拟 |

## 踩坑记录

| 坑 | 说明 |
|----|------|
| 旧版 API | `np.random.rand()` 不可复现，用 `default_rng()` |
| 忘记种子 | 实验没有种子 = 不可复现 = 不可验证 |
| 整数范围 | `integers(1, 7)` 生成 1-6，右端**不包含** |
| `replace` 参数 | `choice(a, replace=True)` 有放回（Bootstrap），`False` 无放回 |
| 内存 | `rng.standard_normal(10_000_000)` 占 80MB，大数据分批生成 |
