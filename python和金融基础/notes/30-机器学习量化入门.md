## 本课核心问题

上一课 [[29-特征工程与数据准备]] 解决的是：如何把原始行情变成可建模的特征。

这一课解决的是：如何把特征真正接到一个机器学习预测闭环里。

核心公式：

$$y_{t+h} = f(X_t) + \varepsilon_{t+h}$$

| 符号 | 含义 | 量化解释 |
|------|------|----------|
| $X_t$ | 当前已知特征 | 动量、波动率、均线偏离、成交量因子 |
| $y_{t+h}$ | 未来标签 | 未来 h 日收益或涨跌方向 |
| $f$ | 模型 | 线性模型、树模型、神经网络等 |
| $\varepsilon$ | 噪声 | 市场不可预测部分 |

---

## ML 量化最小闭环

```text
价格数据 → 特征构造 → 标签构造 → 时间切分 → 模型训练 → 样本外评估 → 策略信号
```

这条流水线比模型本身更重要。模型可以从简单到复杂慢慢升级，但流水线一旦泄漏，所有结果都会失真。

## 1. 标签构造

### 未来收益标签

```python
HORIZON = 5
data["future_ret_5d"] = data["close"].shift(-HORIZON) / data["close"] - 1
```

### 方向标签

```python
data["target_up"] = (data["future_ret_5d"] > 0).astype(int)
```

### 关键原则

| 项目 | 可以用未来吗？ | 说明 |
|------|---------------|------|
| 特征 X | ❌ 不可以 | 必须是 t 时刻已知信息 |
| 标签 y | ✅ 可以 | 标签本来就是训练答案 |
| 预处理参数 | ❌ 测试集不可以参与 | 标准化/去极值只能 fit 训练集 |
| 最终评估 | ✅ 用未来样本 | 但必须样本外，只能 transform/predict |

---

## 2. 时间顺序切分

量化数据不能随机切分。

```python
split = int(len(model_data) * 0.7)
train = model_data.iloc[:split]
test = model_data.iloc[split:]
```

### 为什么不能随机？

| 问题 | 后果 |
|------|------|
| 前视偏差 | 模型间接见过未来 |
| 时序自相关 | 相邻样本高度相似，随机切分高估泛化能力 |
| 市场状态变化 | 牛熊混合后，测试集不再像真实未来 |

## 3. Baseline 模型

本课使用手写 Ridge Regression 作为 baseline：

$$\hat\beta = (X^TX + \lambda I)^{-1}X^Ty$$

### 为什么先做 baseline？

| 原因 | 说明 |
|------|------|
| 可解释 | 能看到每个因子的方向和权重 |
| 稳定 | 不容易因为参数太多过拟合 |
| 快速 | 适合验证标签和切分有没有问题 |
| 对照组 | 后续复杂模型必须超过 baseline 才有意义 |

## 5. 评估指标

不要只看准确率。

| 指标 | 含义 | 常见误区 |
|------|------|----------|
| 方向准确率 | 涨跌方向是否预测正确 | 55% 也可能亏钱 |
| 累计收益 | 策略最终收益 | 可能由少数样本贡献 |
| Sharpe | 单位波动收益 | 忽略尾部风险 |
| 最大回撤 | 最大历史亏损 | 投资体验核心指标 |
| 持仓比例 | 模型触发频率 | 过高像满仓指数，过低可能样本太少 |

完整代码模式：

```python
def sharpe_ratio(ret, periods=252):
    ret = ret.dropna()
    return np.sqrt(periods) * ret.mean() / ret.std()

def max_drawdown(equity):
    running_max = equity.cummax()
    return (equity / running_max - 1).min()
```

## 6. 泄漏检查清单

| 检查点 | 正确做法 |
|--------|----------|
| 特征构造 | 只用当前和历史数据 |
| 标签构造 | 使用 `shift(-h)` 得到未来收益 |
| 缺失值处理 | 参数或规则不能从测试集学习 |
| 标准化 | `fit(train)`，`transform(test)` |
| 切分方式 | 按时间顺序切分 |
| 模型选择 | 测试集不能反复调参 |
| 策略收益 | 信号和收益之间要有时间延迟 |

## 踩坑记录

### 🕳️ 坑1：准确率高但策略亏钱

原因：模型预测对了很多小波动，却错过或做反大波动。

解决：同时看收益、Sharpe、最大回撤，不只看 accuracy。

### 🕳️ 坑2：先标准化全样本再切分

```python
# ❌ 错误
X_scaled = (X - X.mean()) / X.std()
train, test = split(X_scaled)

# ✅ 正确
mean, std = train.mean(), train.std()
train_scaled = (train - mean) / std
test_scaled = (test - mean) / std
```

### 🕳️ 坑3：特征误用了未来数据

例如把 `future_ret_5d` 或未来窗口统计误放进特征列，模型会“神准”，但实盘完全无效。

### 🕳️ 坑4：复杂模型没有超过 baseline

如果 XGBoost、LightGBM 都跑不过线性 baseline，先怀疑特征、标签、评估方式，而不是继续调参。
