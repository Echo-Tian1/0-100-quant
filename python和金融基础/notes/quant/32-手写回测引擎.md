## 回测引擎五大组件

```text
                    ┌──────────────┐
                    │  信号/策略    │  ← 外部输入
                    └──────┬───────┘
                           ↓
┌──────────┐   ┌──────────┐   ┌──────────┐   ┌──────────┐
│  Order   │ → │ Matching │ → │ Account  │ → │Performance│
│ 订单系统  │   │ 撮合引擎  │   │ 账户管理  │   │ 绩效计算  │
└──────────┘   └──────────┘   └──────────┘   └──────────┘
     ↓              ↓              ↓              ↓
  限价/市价      价格检查      现金+持仓       Sharpe/回撤
  方向/数量      滑点模拟      手续费扣除      胜率/盈亏比
```

| 类 | 职责 | 关键逻辑 |
|------|------|------|
| **Order** | 表示一个订单 | 类型(limit/market)、方向、价格、数量、状态 |
| **MatchingEngine** | 撮合成交 | 限价单价格检查、市价单立即成交、滑点模拟 |
| **Account** | 管理资金与持仓 | 现金变动、持仓更新、手续费扣减、计算总市值 |
| **PerformanceCalculator** | 绩效评估 | Sharpe、最大回撤、Calmar、胜率、盈亏比 |
| **BacktestEngine** | 主循环 | 逐日推进、信号→订单→撮合→账户→记录 |

## 1. 订单系统

```python
class OrderType(Enum):
    MARKET = "market"    # 市价单：以当前价立即成交
    LIMIT = "limit"      # 限价单：达到指定价才成交

class OrderSide(Enum):
    BUY = "buy"
    SELL = "sell"

@dataclass
class Order:
    order_id: int
    symbol: str
    order_type: OrderType
    side: OrderSide
    quantity: int
    limit_price: Optional[float] = None
```

## 2. 撮合引擎

最核心的逻辑：什么时候成交、以什么价格成交。

### 市价单

```python
if order.order_type == OrderType.MARKET:
    return md.close  # 直接以收盘价成交
```

### 限价单

```python
if order.side == OrderSide.BUY:
    if md.low <= order.limit_price:
        # 限价买单：市场最低价 ≤ 限价 → 成交
        # 取 min(限价, 收盘价) 对买家有利
        return min(order.limit_price, md.close)
else:
    if md.high >= order.limit_price:
        # 限价卖单：市场最高价 ≥ 限价 → 成交
        return max(order.limit_price, md.close)
```

### 滑点模拟

```python
def _apply_slippage(price, side):
    if side == OrderSide.BUY:
        return price * (1 + slippage)   # 买入价格略高
    else:
        return price * (1 - slippage)   # 卖出价格略低
```

## 3. 账户管理

```python
@dataclass
class Account:
    initial_cash: float = 1_000_000
    cash: float = None
    positions: Dict[str, int] = {}  # symbol → quantity

    def apply_fill(self, fill, current_price):
        if fill.side == OrderSide.BUY:
            cost = fill.price * fill.quantity + fill.fee
            self.cash -= cost
            self.positions[fill.symbol] += fill.quantity
        else:
            revenue = fill.price * fill.quantity - fill.fee
            self.cash += revenue
            self.positions[fill.symbol] -= fill.quantity
    
    def total_value(self, price_map):
        """总市值 = 现金 + 持仓市值"""
        position_value = sum(
            qty * price_map[sym] for sym, qty in self.positions.items()
        )
        return self.cash + position_value
```

### 资金与持仓检查

```python
def can_afford(self, order, price):
    return self.cash >= price * order.quantity * 1.0003

def has_position(self, symbol, quantity):
    return self.positions.get(symbol, 0) >= quantity
```

## 4. 绩效计算

```python
class PerformanceCalculator:
    @staticmethod
    def calculate(position_records):
        navs = [r["total_value"] for r in position_records]
        returns = np.diff(navs) / navs[:-1]
        
        total_return = navs[-1] / navs[0] - 1
        annual_return = (1 + total_return) ** (252 / n) - 1
        annual_vol = np.std(returns) * np.sqrt(252)
        sharpe = (annual_return - 0.02) / annual_vol
        
        peak = np.maximum.accumulate(navs)
        max_dd = (navs - peak).min() / peak
        
        win_rate = (returns > 0).mean()
        profit_loss = gains.mean() / abs(losses.mean())
        
        calmar = annual_return / abs(max_dd)
```

### 绩效指标速查

| 指标 | 公式 | 含义 |
|------|------|------|
| 累计收益 | $NAV_T / NAV_0 - 1$ | 总收益率 |
| 年化收益 | $(1+R)^{252/n} - 1$ | 标准化到年 |
| 年化波动 | $\sigma_{daily} \times \sqrt{252}$ | 风险度量 |
| Sharpe | $(r_{annual} - r_f) / \sigma_{annual}$ | 风险调整收益 |
| 最大回撤 | $\min(NAV_t / peak_t - 1)$ | 最差情况下的亏损 |
| Calmar | $r_{annual} / |MDD|$ | 回撤调整收益 |
| 胜率 | $P(return > 0)$ | 盈利天数占比 |
| 盈亏比 | $E[gain] / E[|loss|]$ | 平均赚/平均赔 |

## 5. 完整引擎主循环

```python
class BacktestEngine:
    def run(self, price_df, signal_fn):
        for i in range(len(price_df)):
            row = price_df.iloc[i]
            md = MarketData(i, row["open"], row["high"], 
                           row["low"], row["close"], row["volume"])
            
            # 信号 → 订单
            orders = signal_fn(i, price_df, self.account)
            
            # 撮合 + 资金检查
            for order in orders:
                fill = self.matcher.match(order, md)
                if fill:
                    if fill.side == BUY and self.account.can_afford(...):
                        self.account.apply_fill(fill, md.close)
                    elif self.account.has_position(...):
                        self.account.apply_fill(fill, md.close)
            
            # 记录快照
            self.account.snapshot(i, price_map)
        
        return PerformanceCalculator.calculate(self.account.position_records)
```

## 手写引擎 vs 成熟框架

| 维度 | 手写引擎 | 成熟框架 |
|------|---------|----------|
| **撮合逻辑** | 简化，自己控制 | 多种撮合模型、订单簿深度 |
| **手续费/滑点** | 简单比例 | 阶梯费率、T+1、涨跌停 |
| **多资产** | 需自己扩展 | 原生支持 |
| **批量回测** | 手动循环 | 参数网格搜索、并行 |
| **可审计性** | 每行代码透明 | 框架内部是黑盒 |
| **学习价值** | 极高 | 低（调包即可） |

**建议**：学习阶段手写引擎理解原理，生产环境用成熟框架保证可靠性。

## 踩坑记录

### 坑 1：忘记手续费
- 很多人回测不算手续费，实盘发现利润被手续费吃掉大半
- ✅ 撮合时立即扣手续费，不要最后再算

### 坑 2：限价单条件写反
- ❌ 限价买单：`market_high <= limit_price` → 永远买不到
- ✅ 限价买单：`market_low <= limit_price` → 只要最低价够低就成交

### 坑 3：资金/持仓检查缺失
- 回测中出现负现金或负持仓，结果毫无意义
- ✅ 每笔成交前都检查 `can_afford()` 和 `has_position()`

### 坑 4：净值快照频率
- 只在成交时记录 → 回撤计算不连续
- ✅ 每个 bar 都记录快照（无论有无成交）
