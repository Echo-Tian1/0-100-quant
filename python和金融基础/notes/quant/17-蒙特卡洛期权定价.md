# 蒙特卡洛期权定价

#期权定价 #蒙特卡洛 #随机模拟 #方差缩减

## 核心概念

### 蒙特卡洛方法的本质

用随机模拟来近似计算期望值：

$$C = e^{-rT} \cdot \mathbb{E}[\max(S_T - K, 0)]$$

**步骤**：
1. 模拟 N 条资产价格路径
2. 计算每条路径的期权 payoff
3. 取平均值作为期望的估计
4. 折现得到期权价格

### 几何布朗运动 (GBM)

资产价格的标准模型：

$$dS = \mu S \, dt + \sigma S \, dW$$

离散化形式：

$$S_{t+\Delta t} = S_t \cdot \exp\left((r - \frac{\sigma^2}{2})\Delta t + \sigma\sqrt{\Delta t} \cdot Z\right)$$

其中 $Z \sim N(0,1)$。

### 标准误差

MC 估计的标准误差：

$$SE = \frac{\sigma_{payoff}}{\sqrt{N}}$$

**关键结论**：
- 精度提高 10 倍 → 需要 100 倍模拟次数
- 收敛速度 $O(1/\sqrt{N})$，比确定性方法慢

### 置信区间

95% 置信区间：

$$\hat{C} \pm 1.96 \cdot SE$$

## 方差缩减技术

### 为什么需要方差缩减？

MC 方法的主要问题是**方差大、收敛慢**。方差缩减技术可以在不增加模拟次数的情况下减小方差。

### 对偶变量法 (Antithetic Variates)

**核心思想**：利用负相关性减小方差。

对于每条路径，同时模拟：
- 路径 A：使用 $Z$
- 路径 B：使用 $-Z$

最终估计：

$$\hat{C} = e^{-rT} \cdot \frac{1}{N/2} \sum_{i=1}^{N/2} \frac{f(S_T^{A,i}) + f(S_T^{B,i})}{2}$$

**为什么有效？**
- $Z$ 导致价格上升，$-Z$ 导致价格下降
- 两者平均后方差减小
- 期望值不变（无偏估计）
- 效率提升约 2-4 倍

### 控制变量法 (Control Variates)

**核心思想**：利用已知解析解的相似产品减小方差。

$$\hat{C}_A = \bar{C}_A - \beta (\bar{C}_B - C_B^{true})$$

最优系数：

$$\beta = \frac{Cov(C_A, C_B)}{Var(C_B)}$$

**常用控制变量**：
- 用几何平均亚式期权（有解析解）控制算术平均亚式期权
- 用标的价格作为控制变量（期望已知）

### 方差缩减效果对比

| 方法 | 效率提升 | 实现难度 | 适用场景 |
|------|----------|----------|----------|
| 标准 MC | 基准 (1x) | 最简单 | 通用 |
| 对偶变量法 | 2-4x | 简单 | 通用 |
| 控制变量法 | 5-10x+ | 中等 | 有相关解析解 |

## 完整代码模式

### 模拟 GBM 路径

```python
import numpy as np

def simulate_gbm_paths(S0, r, sigma, T, M, N):
    """
    模拟几何布朗运动路径
    
    Parameters
    ----------
    S0 : float - 初始价格
    r : float - 无风险利率
    sigma : float - 波动率
    T : float - 到期时间（年）
    M : int - 时间步数
    N : int - 路径数量
    
    Returns
    -------
    np.ndarray : 形状为 (N, M+1) 的路径矩阵
    """
    dt = T / M
    Z = np.random.standard_normal((N, M))
    
    paths = np.zeros((N, M + 1))
    paths[:, 0] = S0
    
    for t in range(M):
        paths[:, t + 1] = paths[:, t] * np.exp(
            (r - 0.5 * sigma**2) * dt + sigma * np.sqrt(dt) * Z[:, t]
        )
    
    return paths
```

### 标准 MC 定价

```python
def mc_european_option(S0, K, r, sigma, T, N, M=252, option_type='call'):
    """蒙特卡洛定价欧式期权"""
    paths = simulate_gbm_paths(S0, r, sigma, T, M, N)
    final_prices = paths[:, -1]
    
    if option_type == 'call':
        payoffs = np.maximum(final_prices - K, 0)
    else:
        payoffs = np.maximum(K - final_prices, 0)
    
    discount = np.exp(-r * T)
    price = discount * payoffs.mean()
    std_error = discount * payoffs.std() / np.sqrt(N)
    
    return {
        'price': price,
        'std_error': std_error,
        'ci_lower': price - 1.96 * std_error,
        'ci_upper': price + 1.96 * std_error
    }
```

### 对偶变量法

```python
def mc_european_antithetic(S0, K, r, sigma, T, N, M=252, option_type='call'):
    """蒙特卡洛定价（使用对偶变量法）"""
    if N % 2 != 0:
        N = N + 1
    
    dt = T / M
    half_N = N // 2
    Z = np.random.standard_normal((half_N, M))
    
    # 正向路径
    paths_pos = np.zeros((half_N, M + 1))
    paths_pos[:, 0] = S0
    
    # 反向路径（对偶）
    paths_neg = np.zeros((half_N, M + 1))
    paths_neg[:, 0] = S0
    
    for t in range(M):
        drift = (r - 0.5 * sigma**2) * dt
        vol = sigma * np.sqrt(dt)
        
        paths_pos[:, t + 1] = paths_pos[:, t] * np.exp(drift + vol * Z[:, t])
        paths_neg[:, t + 1] = paths_neg[:, t] * np.exp(drift - vol * Z[:, t])
    
    if option_type == 'call':
        payoffs_pos = np.maximum(paths_pos[:, -1] - K, 0)
        payoffs_neg = np.maximum(paths_neg[:, -1] - K, 0)
    else:
        payoffs_pos = np.maximum(K - paths_pos[:, -1], 0)
        payoffs_neg = np.maximum(K - paths_neg[:, -1], 0)
    
    payoffs_avg = (payoffs_pos + payoffs_neg) / 2
    
    discount = np.exp(-r * T)
    price = discount * payoffs_avg.mean()
    std_error = discount * payoffs_avg.std() / np.sqrt(half_N)
    
    return {
        'price': price,
        'std_error': std_error,
        'ci_lower': price - 1.96 * std_error,
        'ci_upper': price + 1.96 * std_error
    }
```

### 控制变量法

```python
def mc_european_control_variate(S0, K, r, sigma, T, N, M=252, option_type='call'):
    """蒙特卡洛定价（使用控制变量法）"""
    paths = simulate_gbm_paths(S0, r, sigma, T, M, N)
    final_prices = paths[:, -1]
    
    if option_type == 'call':
        payoffs = np.maximum(final_prices - K, 0)
    else:
        payoffs = np.maximum(K - final_prices, 0)
    
    discount = np.exp(-r * T)
    discounted_payoffs = discount * payoffs
    
    # 用标的价格作为控制变量（其期望已知：S0）
    control = final_prices
    control_mean = S0 * np.exp(r * T)
    
    # 最优 beta
    cov_matrix = np.cov(discounted_payoffs, control)
    beta = cov_matrix[0, 1] / cov_matrix[1, 1]
    
    # 控制变量估计
    controlled_payoffs = discounted_payoffs - beta * (control - control_mean)
    price = controlled_payoffs.mean()
    std_error = controlled_payoffs.std() / np.sqrt(N)
    
    return {
        'price': price,
        'std_error': std_error,
        'ci_lower': price - 1.96 * std_error,
        'ci_upper': price + 1.96 * std_error,
        'beta': beta
    }
```

## MC 方法的优缺点

### 优点

| 优点 | 说明 |
|------|------|
| **灵活** | 可以处理任意 payoff 结构 |
| **路径依赖** | 天然适合路径依赖期权（亚式、障碍等） |
| **高维** | 可以处理多个标的资产 |
| **直观** | 容易理解和实现 |

### 缺点

| 缺点 | 说明 |
|------|------|
| **慢** | 收敛速度 $O(1/\sqrt{N})$，精度提高 10 倍需要 100 倍计算 |
| **方差** | 估计有随机性，每次结果略有不同 |
| **希腊字母** | 计算 Greeks 需要额外技巧 |
| **美式期权** | 不能直接定价美式期权（需要 Longstaff-Schwartz 方法） |

### 何时使用 MC？

- **没有解析解**的复杂期权（亚式、障碍、篮子期权）
- **多资产**期权（相关性问题）
- **路径依赖**期权
- 作为**验证其他方法**的基准

## 踩坑记录

### 1. 随机种子问题
- **问题**：每次运行结果不同，无法复现
- **解决**：设置 `np.random.seed(42)` 或使用新的随机数生成器

### 2. 标准误差计算错误
- **问题**：标准误差比预期大很多
- **原因**：忘记折现，或者用错了标准差公式
- **解决**：`std_error = discount * payoffs.std() / np.sqrt(N)`

### 3. 对偶变量法实现错误
- **问题**：方差没有减小
- **原因**：路径 A 和路径 B 的随机数不是严格的 $Z$ 和 $-Z$
- **解决**：确保 `paths_neg` 使用 `-Z` 而不是独立的随机数

### 4. 深度虚值期权估计不准
- **问题**：深度虚值期权的 MC 价格与 BS 价格差异很大
- **原因**：深度虚值期权的 payoff 几乎都是 0，有效样本太少
- **解决**：使用重要性采样或增加模拟次数

### 5. 路径步数太小
- **问题**：结果与 BS 解析解有系统性偏差
- **原因**：欧拉离散化的误差
- **解决**：增加时间步数 M（通常 M=252 即可）
