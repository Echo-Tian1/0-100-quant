## 移动均线系统

```python
df['MA5']  = df['Close'].rolling(5).mean()   # 短期趋势
df['MA20'] = df['Close'].rolling(20).mean()  # 中期趋势
df['MA60'] = df['Close'].rolling(60).mean()  # 长期趋势
```

### 均线组合的含义

| 组合 | 信号 | 含义 |
|------|------|------|
| 价格 > MA5 > MA20 > MA60 | 多头排列 | 强势上涨 |
| 价格 < MA5 < MA20 < MA60 | 空头排列 | 强势下跌 |
| MA5 上穿 MA20 | 金叉 | 短期买入信号 |
| MA5 下穿 MA20 | 死叉 | 短期卖出信号 |

## 布林带（Bollinger Bands）

$$
\text{中轨} = \text{MA}_{20}, \quad
\text{上轨} = \text{MA}_{20} + 2\sigma_{20}, \quad
\text{下轨} = \text{MA}_{20} - 2\sigma_{20}
$$

```python
df['BB_MID'] = df['Close'].rolling(20).mean()
rolling_std = df['Close'].rolling(20).std()
df['BB_UP'] = df['BB_MID'] + 2 * rolling_std
df['BB_DN'] = df['BB_MID'] - 2 * rolling_std
```

### 布林带交易策略

```python
# 均值回归策略
df['position'] = 0
df.loc[df['Close'] < df['BB_DN'], 'position'] = 1    # 触及下轨 → 买入
df.loc[df['Close'] > df['BB_UP'], 'position'] = -1   # 触及上轨 → 卖出
df['position'] = df['position'].ffill()  # 保持仓位直到反转
```

### 布林带宽度（波动率指标）

```python
df['BB_width'] = (df['BB_UP'] - df['BB_DN']) / df['BB_MID']
# 宽度收窄 → 波动率降低 → 可能即将突破
# 宽度扩大 → 波动率增加 → 趋势行情
```

## 最大回撤（Max Drawdown）

$$
\text{Drawdown}_t = \frac{P_t - P_{peak}}{P_{peak}}, \quad
\text{MDD} = \min_t(\text{Drawdown}_t)
$$

```python
cummax = df['Close'].cummax()                      # 历史最高价
drawdown = (df['Close'] - cummax) / cummax          # 回撤比例（负数）

# 最大回撤
mdd_value = drawdown.min()                          # 最大回撤值
mdd_end = drawdown.idxmin()                         # 终点（最深的那天）
mdd_start = df.loc[:mdd_end, 'Close'].idxmax()      # 起点（之前的最高点）

print(f"最大回撤: {mdd_value:.2%}")
print(f"起止: {mdd_start.date()} → {mdd_end.date()}")
print(f"持续: {(mdd_end - mdd_start).days} 天")
```

### 回撤持续期（恢复到前高需要多久）

```python
# 从回撤终点往后，找到第一次回到前高的日期
peak_price = df.loc[mdd_start, 'Close']
recovery = df.loc[mdd_end:]
recovery_date = recovery[recovery['Close'] >= peak_price].index
if len(recovery_date) > 0:
    print(f"恢复日期: {recovery_date[0].date()}")
    print(f"恢复天数: {(recovery_date[0] - mdd_end).days} 天")
else:
    print("尚未恢复")
```

## 回撤的风险含义

| 回撤幅度 | 需要涨幅恢复 | 风险等级 |
|----------|-------------|---------|
| -10% | +11.1% | 正常波动 |
| -20% | +25% | 修正 |
| -30% | +42.9% | 深度回调 |
| -50% | +100% | 腰斩 |

> 回撤**不对称**：亏 50% 需要赚 100% 才能回本

## 踩坑记录

| 坑 | 说明 |
|----|------|
| `make_addplot` 的 `width` | 不是 `linewidth` |
| `cummax()` 包含当前行 | 所以 `drawdown` 当天可以是 0（创新高时） |
| `idxmin()` 返回索引值 | 如果索引是日期，直接就是日期对象 |
| `axvspan` 传入日期 | 需要是 DatetimeIndex 的元素，不能是字符串 |
