## 风控三层体系

```text
信号 → 订单 → [凯利仓位] → 撮合 → [ATR止损检查] → [回撤限制] → 账户更新
         ↑                    ↑         ↑               ↑
      下多少？              成交前    已有持仓止损     全局熔断
```

| 层级 | 风控模块 | 管什么 | 机制 |
|------|---------|--------|------|
| 第一层 | 凯利公式 | 仓位大小 | 根据历史胜率/盈亏比动态计算投注比例 |
| 第二层 | ATR 止损 | 单笔亏损 | 根据当前波动率自适应止损距离 |
| 第三层 | 回撤限制 | 全局风控 | 账户回撤超阈值暂停交易，恢复后重启 |

## 1. 凯利公式

### 公式

$$f^* = \frac{p \cdot b - (1-p)}{b}$$

- $p$：胜率 | $b$：盈亏比 | $f^*$：最优投注比例

### 示例

$p=0.6, b=2$ → $f^* = (0.6×2 - 0.4)/2 = 0.4$，投 40% 资金。

### 业界修正

| 修正方式 | 比例 | 说明 |
|----------|------|------|
| 全仓凯利 | $f^*$ | 理论最优，但回撤可能超过心理承受力 |
| 半凯利 | $f^* / 2$ | 业界常用，平衡收益与风险 |
| 四分之一凯利 | $f^* / 4$ | 保守策略，回撤最小 |

```python
class KellyPositionSizer:
    def __init__(self, kelly_fraction=0.5, max_position_pct=0.25):
        self.kelly_fraction = kelly_fraction  # 半凯利
    
    def compute_kelly(self, win_rate, profit_loss_ratio):
        if profit_loss_ratio <= 0 or win_rate <= 0:
            return 0.0
        f_star = (win_rate * profit_loss_ratio - (1 - win_rate)) / profit_loss_ratio
        return max(0.0, f_star)
    
    def position_size(self, capital, price, win_rate, profit_loss_ratio):
        kelly_f = self.compute_kelly(win_rate, profit_loss_ratio)
        adjusted_f = min(kelly_f * self.kelly_fraction, self.max_position_pct)
        amount = capital * adjusted_f
        return int(amount / price)
```

## 2. ATR 动态止损

### 为什么不用固定百分比？

| 场景 | 固定 -5% 止损 | ATR 止损 |
|------|-------------|----------|
| 高波动市场 | 容易被震出 | 自动放宽止损 |
| 低波动市场 | 止损太宽 | 自动收紧止损 |

### True Range 计算

$$TR = \max(H-L, |H-C_{prev}|, |L-C_{prev}|)$$

ATR = TR 的 EMA（指数移动平均）。

### 止损价格

$$\text{stop\_price} = \text{entry\_price} - N \times \text{ATR}$$

（N 通常取 2）

```python
class ATRStopLoss:
    def __init__(self, atr_period=14, atr_multiplier=2.0):
        ...
    
    def compute_atr(self, high, low, close):
        tr1 = high - low
        tr2 = |high - prev_close|
        tr3 = |low - prev_close|
        true_range = max(tr1, tr2, tr3)
        # EMA 平滑
        atr[i] = alpha * true_range[i] + (1-alpha) * atr[i-1]
    
    def stop_price(self, entry_price, atr_value, side="long"):
        band = self.atr_multiplier * atr_value
        return entry_price - band  # 做多
        # return entry_price + band  # 做空
    
    def is_stopped(self, current_low, stop_loss_price):
        return current_low <= stop_loss_price  # 盘中最低价触及止损
```

## 3. 最大回撤限制

全局熔断机制：账户从峰值回撤超过阈值 → 停止所有新交易。

| 参数 | 值 | 含义 |
|------|-----|------|
| max_drawdown_pct | 20% | 回撤超过此值触发熔断 |
| recovery_pct | 10% | 回撤恢复到该水平以下才允许重新交易 |

```python
class DrawdownLimiter:
    def update(self, current_nav):
        self.peak_nav = max(self.peak_nav, current_nav)
        current_dd = (current_nav - self.peak_nav) / self.peak_nav
        
        if self.trading_halted:
            if abs(current_dd) < self.recovery_pct:
                self.trading_halted = False  # 恢复
            return False
        
        if abs(current_dd) >= self.max_drawdown_pct:
            self.trading_halted = True  # 触发熔断
            return False
        
        return True  # 正常交易
```

## 5. 实战对比结果

同一策略 + 同一数据，开/关风控：

| 指标 | 无风控 | 有风控(凯利+ATR+DD) |
|------|--------|---------------------|
| 累计收益 | 看市场 | （牛市略低，熊市明显更好） |
| 最大回撤 | 可能很大 | 受 20% 熔断限制 |
| 仓位特征 | 固定股数 | 凯利动态调整 |
| 风控暂停 | 无 | 熊市中可能触发 |

核心结论：**风控在熊市中体现价值**——牛市里风控可能限制收益，但在趋势反转时能保住本金。

## 6. 凯利公式的局限

| 局限 | 说明 |
|------|------|
| 参数估计误差 | 胜率/盈亏比从历史估计，未来不一定成立 |
| 非独立投注 | 凯利假设每次独立，但交易有序列相关 |
| 回撤容忍度 | 全仓凯利回撤远超心理承受力 |
| 多资产不适用 | 经典凯利是单次投注模型 |
| 尾部风险 | 不防御黑天鹅，假设收益分布已知 |

**三者各司其职**：凯利管"下多少"、ATR管"单笔亏多少"、回撤限制管"整体亏多少"。

## 踩坑记录

### 坑 1：直接用全仓凯利
- ❌ $f^*=0.4$ 就投 40%，一次连亏三次就亏掉 78%
- ✅ 用半凯利 + 25% 上限

### 坑 2：凯利用未来信息
- ❌ 拿整个回测周期的胜率来算凯利（前视偏差）
- ✅ 只用当前时刻之前的交易记录估计

### 坑 3：ATR 止损太紧
- ATR 乘数取 1 会被正常波动震出
- 常用 2 倍 ATR，约等于 2 个标准差

### 坑 4：回撤恢复条件设得太松
- ❌ 回撤刚触及熔断线就立即恢复（来回触发）
- ✅ 恢复到一半水平才允许重新交易
