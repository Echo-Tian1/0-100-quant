### 关键估值指标

| 指标 | 含义 | 合理范围 | 备注 |
|------|------|----------|------|
| **PE** (市盈率) | 股价 / 每股收益 | 10-30 | 排除负值（亏损股） |
| **PB** (市净率) | 股价 / 每股净资产 | 1-5 | <1 为破净 |
| **市值** | 总股本 × 股价 | >50亿 | 排除小盘股 |

## 🔧 完整代码模式

### 数据获取

```python
import akshare as ak
import pandas as pd

# 获取全 A 股实时行情
df = ak.stock_zh_a_spot_em()

# 关键列选取
df_clean = df[['代码', '名称', '最新价', '市盈率-动态', '市净率', '总市值', '行业']]
df_clean.columns = ['code', 'name', 'price', 'pe', 'pb', 'market_cap', 'industry']
```

### 多条件筛选

```python
# 市值转换为亿元
df_clean['market_cap_yi'] = df_clean['market_cap'] / 1e8

# 多条件布尔索引
mask = (
    (df_clean['pe'] > 0) &
    (df_clean['pe'] < 50) &
    (df_clean['market_cap_yi'] > 50) &
    (df_clean['pb'] > 0)
)

df_filtered = df_clean[mask]
```

### 行业聚合分析

```python
industry_stats = df_filtered.groupby('industry').agg(
    count=('code', 'count'),
    avg_pe=('pe', 'mean'),
    avg_pb=('pb', 'mean'),
    total_market_cap=('market_cap_yi', 'sum')
).round(2).sort_values('count', ascending=False)
```

## ⚠️ 踩坑记录

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| PE 列有负值 | 亏损股市盈率为负 | 筛选时加 `pe > 0` 条件 |
| 市值单位不对 | 接口返回的是"元"不是"亿" | 除以 1e8 转换为亿元 |
| 行业列缺失 | 部分接口不含行业信息 | 需单独调用行业板块接口获取 |
| 数据类型错误 | 字符串混入数值列 | 用 `pd.to_numeric(errors='coerce')` 转换 |

## 📊 可视化解读

### 饼图
- 展示筛选后股票的行业分布
- 行业集中度反映市场估值洼地

### 散点图
- **左下角**：低 PE + 低 PB = 价值股机会
- **右上角**：高 PE + 高 PB = 成长股高估值
- **点大小**：反映市值，大盘股更稳定

### 柱状图
- 对比各行业平均估值水平
- 颜色深浅反映估值高低
