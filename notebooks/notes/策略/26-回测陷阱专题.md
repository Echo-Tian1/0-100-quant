## 六大回测陷阱

### 1. 幸存者偏差（Survivorship Bias）

**现象**：用当前还在的股票回测历史策略 → 已退市/ST 的表现最差者被剔除 → 结果虚高

**应对**：
- 用历史成分股（Point-in-Time 数据）
- 了解回测期间哪些股票退市了
- 无 PoD 数据时，至少做敏感性分析（假设不同退市率）

### 2. 前视偏差（Look-ahead Bias）

**现象**：t 时刻用了 t 之后才有的信息

最常见的三种：
- 用全样本均值和标准差做信号（而非滚动窗口）
- 财务数据发布时间错位
- 用后复权价格回测（包含了未来的分红拆股信息）

**应对**：严格使用 expanding / rolling window，所有计算只用当前时点之前的数据

### 3. 过拟合（Overfitting）

**现象**：参数优化学到了样本内噪音 → 样本外表现大幅衰减

识别信号：
- 样本内夏普 > 3
- 参数微调 → 收益剧烈变化
- 参数越多 → 过拟合风险越大

**应对**：
- 样本外保留（hold-out）
- 简单策略优先（Occam's Razor）
- 交叉验证（时序用 expanding window）

### 4. 忽略交易成本

**现象**：回测收益是纸面富贵，扣完手续费、滑点、冲击成本后可能亏损

A 股成本参考：佣金 0.025% + 印花税 0.05%（卖出）= 双边约 0.075%-0.15%

**应对**：回测中必须加入交易成本，高频策略尤其敏感

### 5. 数据窥探（Data Snooping）

**现象**：试了 N 个策略 / N 组参数，挑最好的展示 → 那个"最好"可能只是随机波动

数学本质：
- 假设真实夏普 = 0，试 100 个策略
- 纯靠运气也能发现夏普 ≈ 2 的策略

**应对**：
- Bonferroni 校正（p × N）
- 经济逻辑先行，而非纯数据挖掘
- 样本外验证

### 6. 样本选择偏差

**现象**：策略只在特定标的 / 特定时段有效

**应对**：多标的、多时段、多市场交叉验证

## 黄金法则

> **任何回测在样本外验证和实盘之前，都是"好看的故事"——不是证据。**

1. 样本外数据是圣杯——回测阶段绝对不能碰
2. 策略越简单越好——参数越多，过拟合风险越大
3. 成本是真实的——不加成本的夏普不算数
4. 问自己：这个策略有经济逻辑吗？
5. 夏普 > 2 → 先怀疑自己哪里写错了
