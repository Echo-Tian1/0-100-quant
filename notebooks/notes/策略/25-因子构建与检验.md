## 核心概念

### 因子（Factor）
可量化的股票特征，用于预测未来收益。三类核心因子：
- **估值因子**：E/P（盈利收益率）、B/P（账面市值比）—— 便宜的公司收益更高
- **动量因子**：12-1月动量（Jegadeesh-Titman, 1993）—— 强者恒强
- **质量因子**：ROE、毛利率、低杠杆 —— 优质公司长期跑赢

### IC（Information Coefficient，信息系统）
$$IC_t = \text{corr}(\text{Factor}_{t}, \text{Return}_{t+1})$$

衡量因子值与未来收益的相关性：
| IC 绝对值 | 评价 |
|-----------|------|
| > 0.05 | 🌟 优秀因子 |
| 0.03-0.05 | ✅ 良好因子 |
| 0.02-0.03 | ⚠️ 可用因子 |
| < 0.02 | ❌ 弱因子 |

- **Rank IC**（Spearman）：更稳健，推荐使用
- **Normal IC**（Pearson）：对异常值敏感

### IR（Information Ratio，信息比率）
$$IR = \frac{\text{mean}(IC)}{\text{std}(IC)}$$

$$IR_{annual} = IR_{daily} \times \sqrt{252}$$

衡量因子预测能力的**一致性**：
- IR > 0.5 → 优秀
- IR > 0.3 → 良好

**IC vs IR**：IC 衡量预测力大小，IR 衡量预测力稳定性。高 IC 但低 IR = "时灵时不灵"。

### 因子衰减（Factor Decay）

IC 随持有期增加而下降 → **半衰期**（IC 降至初始一半的时间）。

原因：
1. **市场学习**：套利者复制因子 → 超额收益消失
2. **因子拥挤**：资金涌入 → 估值泡沫
3. **逻辑失效**：市场结构变化

应对：缩短调仓周期、因子轮动、复合因子

### 因子拥挤（Factor Crowding）

过多资金追逐同一因子：
- 因子估值泡沫（多空组合价差异常扩大）
- 踩踏风险（2007 Quant Quake）
- 波动率黑洞（表面上低波动，风险暗中积累）

识别信号：因子估值处历史高位、个股相关性异常升高、主动基金集中暴露

## 因子预处理流程

```
原始因子 → 去极值(MAD法, ±5×MAD) → 标准化(Z-score) → 正交化(对称回归)
```

### 去极值 - MAD法
$$\tilde{x} = \text{median}(x), \quad \text{MAD} = \text{median}(|x_i - \tilde{x}|)$$
超过 $\tilde{x} \pm 5 \times \text{MAD}$ → 拉回边界

### 正交化
因子间存在相关性（低估值的往往质量也好）→ 共线性影响回测
- **对称正交化**：每个因子对其他所有因子回归，取残差
- 正交化后因子间相关性 ≈ 0

## 踩坑记录

1. **未来数据泄露**：计算因子时只能用 t 时刻及之前的信息，不能"偷看"未来
2. **存活者偏差**：因子分析只能用当时存在的股票，不能用现在还在的股票回溯
3. **忽略交易成本**：IC 看起来好但实际不可交易（小市值、高换手）
4. **单期 IC ≠ 稳定**：一个截面的 IC 没有统计意义，需要多期序列
5. **IC 衰减不一定是坏事**：动量因子天然衰减快但调仓频繁仍可盈利
