## 核心概念

### 双均线策略

用两条不同周期的移动平均线捕捉趋势：

- **短期均线 (fast MA)**：对价格敏感，反应快但噪音多
- **长期均线 (slow MA)**：趋势平滑，反应慢但假信号少

**金叉 (Golden Cross)**：短期均线 **上穿** 长期均线 → 买入信号（看涨趋势确立）  
**死叉 (Dead Cross)**：短期均线 **下穿** 长期均线 → 卖出信号（看跌趋势确认）

数学上，信号可以表达为：

```
SMA_n(t) = (1/n) * Σ_{i=0}^{n-1} P_{t-i}

Signal(t) = 1  if SMA_fast(t) > SMA_slow(t)
            0  otherwise
```

### 为什么需要参数优化？

不同的资产和市场需要不同的均线窗口。A 股和美股的最优参数不同，大盘股和小盘股不同，不同时间段也不同。需要通过参数搜索找到当前环境下的较优组合。

## 完整代码模式

### VectorBT 双均线回测模板

```python
import vectorbt as vbt
import pandas as pd

# 1. 准备数据
close = df['close']  # 日收盘价

# 2. 计算均线
fast_ma = vbt.MA.run(close, window=10)
slow_ma = vbt.MA.run(close, window=50)

# 3. 生成买卖信号
entries = fast_ma.ma_crossed_above(slow_ma)   # 金叉 → 买入
exits = fast_ma.ma_crossed_below(slow_ma)     # 死叉 → 卖出

# 4. 回测
pf = vbt.Portfolio.from_signals(
    close, entries, exits,
    freq='1D',
    init_cash=100000,
    fees=0.001,       # 0.1% 手续费 — 不要漏
    slippage=0.001    # 0.1% 滑点
)

# 5. 查看绩效
print(pf.stats())
```

### 参数网格搜索模板

```python
import itertools

fast_windows = range(5, 55, 5)
slow_windows = range(20, 130, 10)

results = []
for fast_w, slow_w in itertools.product(fast_windows, slow_windows):
    if fast_w >= slow_w:
        continue  # 快线必须短于慢线

    fast_ma = vbt.MA.run(close, window=fast_w)
    slow_ma = vbt.MA.run(close, window=slow_w)
    
    entries = fast_ma.ma_crossed_above(slow_ma)
    exits = fast_ma.ma_crossed_below(slow_ma)
    
    pf = vbt.Portfolio.from_signals(
        close, entries, exits,
        freq='1D', init_cash=100000,
        fees=0.001, slippage=0.001
    )
    
    results.append({
        'fast': fast_w,
        'slow': slow_w,
        'sharpe': pf.sharpe_ratio(),
        'ann_return': pf.annualized_return(),
        'max_dd': pf.max_drawdown(),
        'n_trades': len(pf.trades),
        'win_rate': pf.trades.win_rate(),
    })

df_results = pd.DataFrame(results)
best = df_results.sort_values('sharpe', ascending=False).iloc[0]
```

### 样本内 vs 样本外

|  | 样本内 (In-Sample) | 样本外 (Out-of-Sample) |
|--|-------------------|----------------------|
| 用途 | 训练、参数优化 | 评估、检验泛化 |
| 数据 | 前 80% 历史数据 | 后 20% 历史数据 |
| 夏普比 | 乐观（含有过拟合） | 真实（接近实际表现） |
| 规则 | 可以反复使用 | 只能使用一次 |

### 过拟合信号识别

| 信号 | 说明 | 严重程度 |
|------|------|----------|
| 样本内 → 样本外夏普衰减 > 50% | 策略几乎无泛化能力 | 🔴 严重 |
| 衰减 30-50% | 有泛化但不可靠 | 🟡 警惕 |
| 衰减 < 30% | 策略相对稳定 | 🟢 可接受 |
| 最优参数是「孤岛」 | 相邻参数表现突然变差 | 🔴 数据挖掘嫌疑 |
| 不同时间段最优参数不一致 | 参数不稳定 | 🟡 需检验 |

## 踩坑记录

### 坑 1：没有样本外验证就上实盘

❌ 在全部历史上找到最优参数，直接实盘  
✅ 必须划分样本内/外，样本外用于最终验证

> 这是量化新手最常见的错误。样本内找到的"最优"参数 100% 含有过拟合成分。

### 坑 2：忽略手续费和滑点

❌ `fees=0, slippage=0` 的回测结果  
✅ 至少加 0.1% 手续费 + 0.1% 滑点

> 手续费对高频策略是致命的。双均线策略频率中等，0.1% 的手续费就能吃掉不少收益。

### 坑 3：搜索空间过大

❌ fast: 1-200 天, slow: 2-300 天 → 上万个组合  
✅ fast: 5-50 天 (步长5), slow: 20-120 (步长10) → 几十个组合

> 搜索空间越大，找到纯幸运好参数的概率越高。参数数量控制：2-3 个是安全上限。

### 坑 4：用夏普比排序就选第一

```
真实做法：
1. 看热力图 — 最优参数附近是否平滑？
2. 看样本外 — 衰减幅度多大？
3. 看交易次数 — 少于 30 笔的结果不可信
4. 看经济直觉 — 参数的金融含义是否合理？
```

### 坑 5：VectorBT 的 `from_signals` 买卖信号混用

```python
# ❌ 错误：用同一个信号做 entry 和 exit
entries = exits = ma_cross(...)
pf = vbt.Portfolio.from_signals(close, entries, exits)

# ✅ 正确：金叉买，死叉卖
entries = fast_ma.ma_crossed_above(slow_ma)
exits = fast_ma.ma_crossed_below(slow_ma)
```

## 关键绩效指标速查

| 指标 | 公式/含义 | 好/坏判断 |
|------|----------|----------|
| 夏普比 | (年化收益 - 无风险利率) / 年化波动率 | > 1.0 可接受，> 2.0 优秀 |
| 最大回撤 | 峰到谷的最大跌幅 | < 20% 可接受，> 40% 危险 |
| Calmar 比 | 年化收益 / 最大回撤 | > 1.0 良好 |
| 胜率 | 盈利交易 / 总交易 | > 40% 即可（配合高盈亏比） |
| 盈亏比 | 平均盈利 / 平均亏损 | > 1.5 可接受 |
