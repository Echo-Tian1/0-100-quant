## 策略逻辑：动量效应

### Jegadeesh-Titman (1993) 核心发现

过去 **3-12 个月** 表现好的股票，在未来 **3-12 个月** 继续表现好。

### 行为金融解释

| 机制 | 说明 |
|------|------|
| **反应不足** | 投资者对新信息消化缓慢，股价缓慢调整 |
| **处置效应** | 投资者过早卖出盈利股、持有亏损股 |
| **羊群效应** | 追涨杀跌的正反馈强化趋势 |

### 本报告策略规则

| 参数 | 取值 | 说明 |
|------|------|------|
| 股票池 | 沪深300成分股 | 流动性好 |
| 动量计算期 | 12个月（跳过最近1月） | 标准 JT 设定 |
| 持有期 | 1个月 | 月度调仓 |
| 持仓数量 | Top 20 | 等权配置 |
| 交易成本 | 双边 0.15% | 佣金+印花税+滑点 |
| 基准 | 沪深300等权买入持有 | 被动策略对比 |

### 为什么要跳过最近1个月？

短期反转效应（Jegadeesh 1990）：最近1个月收益与未来收益**负相关**——涨多了会回调。跳过最近1个月可以过滤这种噪声。

## 回测引擎设计

### 核心逻辑

```python
def backtest_momentum(price_df, top_n=20, lookback=12, skip=1, cost_rate=0.0015):
    """
    每月末：
    1. 计算过去 lookback 个月（跳过最近 skip 个月）的累计收益
    2. 选 Top N 等权持有
    3. 计算换手率，扣除双边交易成本
    4. 记录组合收益
    """
```

### 关键设计点

| 要点 | 实现方式 |
|------|---------|
| **动量计算** | `(1 + past_ret).prod() - 1` — 累计收益而非平均收益 |
| **成本扣除** | `net_ret = next_ret - turnover * cost_rate * 2` |
| **换手率** | `(sold + bought) / (2 * top_n)` — 售出+买入的股票占比 |
| **等权配置** | `next_ret.iloc[top_stocks].mean()` — 简单平均 |

## 样本内外划分 —— 策略验证的唯一标准

### 严格的时序划分

| 区间 | 时间范围 | 用途 | 规则 |
|------|---------|------|------|
| **样本内（训练）** | 2021-01 ~ 2024-12 (48个月) | 理解策略、调参 | 可以反复看 |
| **样本外（测试）** | 2025-01 ~ 2026-06 (18个月) | 验证策略 | **绝对不碰，只用一次** |

> ⚠️ 样本外数据在策略开发中绝不能用于调试或调参，否则退化回样本内——验证失效。

### 判断标准

| 样本内表现 | 样本外表现 | 解读 |
|-----------|-----------|------|
| 好 | 好 | ✅ 策略稳健，参数有泛化能力 |
| 好 | 差 | ❌ 过拟合——样本内只是记住了历史 |
| 差 | 好 | 🤔 奇怪——检查数据泄露 |
| 差 | 差 | ❌ 策略无效 |

## 风险分析指标体系

### 核心风险指标

| 指标 | 公式/定义 | 能回答的问题 |
|------|----------|-------------|
| **最大回撤 (MaxDD)** | $\max(\frac{Cum_t}{\max_{s \le t} Cum_s} - 1)$ | 最惨的时候亏了多少？ |
| **VaR (95%/99%)** | 收益率分布的 5%/1% 分位数 | 95%/99% 概率下，一个月最多亏多少？ |
| **CVaR (95%/99%)** | 超过 VaR 的平均损失 | 如果真的发生极端亏损，平均亏多少？ |
| **偏度 (Skewness)** | $\frac{E[(X-\mu)^3]}{\sigma^3}$ | 收益分布是对称的还是有偏的？ |
| **超额峰度 (Kurtosis)** | $\frac{E[(X-\mu)^4]}{\sigma^4} - 3$ | 极端值（暴跌）比正态分布多还是少？ |
| **Calmar 比率** | $\frac{年化收益}{\vert 最大回撤\vert}$ | 每承担1%最大回撤能赚多少？ |
| **月度胜率** | 正收益月份占比 | 赚钱的概率有多大？ |
| **盈亏比** | $\frac{正收益均值}{\vert负收益均值\vert}$ | 赚的时候比亏的时候多多少？ |

### VaR vs CVaR

| | VaR | CVaR |
|------|-----|------|
| 含义 | 阈值（不会比这更差） | 超过阈值后的平均损失 |
| 优点 | 简单直观 | 考虑了尾部损失的严重程度 |
| 缺点 | 不关心尾部有多差 | 对尾部估计敏感 |
| 监管偏好 | Basel II | Basel III（逐步替代 VaR） |

> CVaR 回答：**"如果情况真的很糟，平均会亏多少？"** —— 这比 VaR 更能反映真实风险。

### 偏度与峰度的实战意义

| 偏度 | 峰度 | 说明 |
|------|------|------|
| 负偏 (< -0.5) | — | 左尾长，暴跌风险大于暴涨机会 |
| 正偏 (> 0.5) | — | 右尾长，有非对称的暴涨机会 |
| — | 超额峰度 > 0 | **肥尾**——极端事件比正态分布假设的多得多 |

## 绩效归因：收益从哪来？

### Fama-French 五因子归因

$$R_P - R_f = \alpha + \beta_{MKT} \cdot MKT + \beta_{SMB} \cdot SMB + \beta_{HML} \cdot HML + \beta_{RMW} \cdot RMW + \beta_{CMA} \cdot CMA + \varepsilon$$

| 符号 | 含义 | 解读 |
|------|------|------|
| **α (Alpha)** | 截距项 | **真正的技能** — 因子无法解释的那部分 |
| β_MKT | 市场暴露 | 搭了市场上涨的顺风车 |
| β_SMB | 规模因子 | 买的是小盘股吗？ |
| β_HML | 价值因子 | 买的是便宜股吗？ |
| β_RMW | 盈利因子 | 买的是高盈利股吗？ |
| β_CMA | 投资因子 | 买的是保守投资股吗？ |

### 归因结果解读

```
年化 Alpha: +X.XX%   (t=Y.YY, p=0.0Z)
R²: 0.XX
```

| Alpha 情况 | 含义 | 后续行动 |
|-----------|------|---------|
| α > 0, p < 0.05 | 有统计显著的选股能力 | ✅ 策略有真实超额收益 |
| α > 0, p > 0.1 | 看起来赚了，但可能是运气 | ⚠️ 需要更长回测期验证 |
| α ≈ 0 | 收益完全来自因子暴露 | 策略只是 Beta 投资，不是 Alpha |
| α < 0 | 扣除风险后实际在亏钱 | ❌ 策略无效 |

## 策略局限性

### 动量策略的固有缺陷

| 局限 | 说明 | 严重程度 |
|------|------|---------|
| **动量崩溃** | 市场急转弯时（如 2009 反弹），动量策略大幅回撤 | 🔴 致命 |
| **容量限制** | 小市值股票流动性不足，大资金无法复制 | 🟡 中等 |
| **因子拥挤** | 越来越多动量基金可能压缩 Alpha | 🟡 中等 |
| **参数敏感性** | 动量期、持仓数调一点结果差很多 | 🟡 中等 |

### 适用条件矩阵

| 市场环境 | 动量策略表现 |
|----------|------------|
| 趋势市（牛市/熊市） | ✅ 效果好 |
| 震荡盘整市 | ⚠️ 频繁换手 + 反复打脸 |
| 风格剧烈切换 | ❌ 动量崩溃风险高 |
| 流动性紧缩 | ❌ 成本上升 |

## 改进方向

1. **价值动量**：只买便宜的动量股 → 用估值因子过滤，规避动量崩溃
2. **止损机制**：单月回撤超 X% 减仓 → 尾部风险控制
3. **扩展股票池**：中证500 + 中证1000 → 更多候选，更高分散度
4. **机器学习增强**：用 [[29-特征工程与数据准备|XGBoost]] 预测动量持续性
