从零开始学量化分析的个人学习仓库。

```

   01-03       04-07       08-11       12-15      16-18      19-21      22-28       29-34
```

## 快速开始

```bash
# 克隆仓库
git clone https://github.com/Echo-Tian1/0-100-quant.git
cd 0-100-quant

# 安装依赖
pip install -r requirements.txt

# 启动 Jupyter
jupyter notebook notebooks/
```

**主要依赖**

| 库 | 用途 | 涉及课时 |
|----|------|---------|
| numpy | 数值计算与线性代数 | 全课程 |
| pandas | 数据处理与时间序列 | 全课程 |
| matplotlib | 可视化与图表 | 08-11, 22-34 |
| scipy | 统计检验与优化 | 10, 20, 34 |
| akshare | A 股数据获取 | 05, 07, 09, 11 |
| mplfinance / seaborn | 金融图表与统计图 | 08-11, 22-34 |
| vectorbt | 向量化回测 | 22 |
| backtrader | 事件驱动回测 | 24 |
| statsmodels | 回归与统计建模 | 12-15, 27 |
| PyPortfolioOpt | 组合优化工具 | 20-21 |
| scikit-learn | 机器学习模型 | 29-31, 34 |
| lightgbm | 梯度提升树（可选增强） | 30-31 |

QLib 属于重型可选框架，第 31 课提供 mini-QLib 手写实现；如果要运行官方 QLib，可额外安装 `pyqlib`。

绝大多数 notebook 在无网络环境下仍可运行（内置模拟数据降级）。

## 学习建议

- **纯新手**：按 01→02→…→34 顺序学习，前期每课约 1-2 小时，后期（29-34）每课约 3-5 小时
- **有 Python 基础**：可从 04（Pandas 时序）直接开始，01-03 根据需要回顾
- **有金融背景**：可从 12（CAPM）进入理论部分，再补数据处理基础
- **只对某个主题感兴趣**：直接定位到对应阶段，01-28 课之间依赖较弱，29-34 课建议连续学习
- **准备面试**：重点看 28（策略报告）和 34（全流程项目），这两课直接对应面试中的项目展示环节

## 关于数据

Notebook 中优先使用 AKShare 获取真实 A 股数据。网络不可用时自动降级为固定随机种子的模拟数据，保证所有代码可复现运行。
