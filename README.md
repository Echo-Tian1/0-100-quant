# 0-100 Quant

从零开始学量化分析的个人学习仓库。

## 为什么做这个项目

我从 2024 年底开始对量化投资感兴趣，发现中文的系统性资料比较少，大多是比较碎片化的博客或者收费课程。所以我决定边学边整理，把学习过程中的代码和笔记都记录下来。

这个仓库目前包含 33 个 Jupyter Notebook，从 Python 基础到组合优化、策略开发、ML 量化和风控系统，覆盖了量化分析的主要环节。每个 Notebook 都有完整的代码和注释，可以直接运行。

## 快速开始

```bash
# 克隆仓库
git clone https://github.com/Echo-Tian1/0-100-quant.git
cd 0-100-quant

# 安装依赖
pip install -r requirements.txt

# 启动 Jupyter
jupyter notebook notebooks/
```

主要依赖：numpy、pandas、matplotlib、akshare、scipy

## 学习建议

- 如果有 Python 基础，可以从第 4 个 Notebook 开始
- 如果是纯新手，建议按顺序学习，每个 Notebook 大约 1-2 小时
- 如果只对某个主题感兴趣，可以直接看对应的 Notebook

## 关于数据

Notebook 中使用的数据主要来自 AKShare（A 股数据）。如果网络不好，部分 Notebook 提供了模拟数据作为备选。
